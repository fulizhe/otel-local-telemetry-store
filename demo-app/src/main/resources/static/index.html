存储读口

存储已经能用了，但只有 JMX 那条读口。本页读不到它 —— HTTP 读口是下一阶段的事。数据确实落库了，查看方式：

jconsole 连本进程 → MBeans → io.github.fulizhe.otelstore → LocalStoreSummary，下面四个直接可点：
summary（全量计数）· recentSpans(10)（最近 10 条 span 表头）· spansOfTrace(<trace_id>)（按 trace 取回全部 span）· spanPayloadHex(<id>)（读回单条的环形载荷）。

对账：上表的条数应当与 spanRows() 对得上，差额来自采样与丢弃 （head sampling 与 SDK 截断在原理上不可计数，只能这样对照发现）。

跨源已经定了：HTTP 读口做完后浏览器直接打开读口那侧（http://<host>:17890/）， 读口不开 CORS、本页不加代理 —— 代价是那个页面不在本页导航里、要另开标签页， 换来的是少一个开放面（开 CORS 等于允许任意站点读你的 trace）。 实际端口若因冲突退到了随机值，会写在 otel-local-telemetry-store/otelstore.port 与启动日志里。
