一页一条线

span
调用链。按 trace_id 过滤整条链；点行看属性与事件。
日志
应用自己产出的日志。点行看完整正文与 trace 关联。
指标
指标点的时间序列。直方图给桶上界与累计计数。
自监控
扩展自身：生效配置、库状态、自监控指标。
自日志
扩展自己写的日志（降级、限速告警、周期汇总）。刷新比自监控页快。

给脚本用的入口

端点给谁
/metricsPrometheus 抓取。标签只有 attr_key 哈希（ADR-6 第十一节，已知取舍）
/api/summary计数与健康快照的 JSON
/api/traces /api/logs /api/metrics上面三个列表页各自的数据源
/api/self-log自日志页的数据源（尾部若干行，默认 100、上限 500）
/api/traces/{id} /api/logs/{id}详情弹窗的数据源（只解，不给下载）
这一页不含任何数据，数据都由页面里的 JS 带头去取 —— 所以本页不需要 token，/api/* 才需要。
