「结构」列是解析过的，不是原文：直方图给「桶上界 → 累计计数」， 摘要给各分位点。桶上界与累计由服务端算好（桶比边界多一个，末尾是 +∞）。
图上画的是哪个量，写在图例里：Gauge 画「值」、Sum 画「求和」、 Histogram / Summary 没有单一的值，画的是「计数」。 图例里的 ·attr 是属性组合的哈希不是属性 （ADR-6 第十一节）—— 拿不到属性原文，就不拿哈希冒充属性名。
「认不出来」不是故障 —— 它说明这个数据点的 detail 形态没被覆盖， 原文在单元格的 title 里。要看解释见 自监控。
